# Vitrine de Passeios

Este site foi criado para servir como um catálogo digital para uma agência de passeios. O grande diferencial técnico é a geração dinâmica das páginas: em vez de criar um arquivo HTML para cada passeio, o sistema lê um arquivo central em formato .json e gera automaticamente as rotas e interfaces correspondentes.

## ✨ Funcionalidades 
* **Geração Dinâmica de Conteúdo:** Adicione ou remova passeios apenas editando o arquivo data.json.

* **Páginas de Detalhes:** Cada passeio possui sua própria página exclusiva com informações detalhadas, fotos e preços.

* **Design Responsivo:** Otimizado para visualização em smartphones, tablets e desktops.

* **Interface Intuitiva:** Focada na conversão e na experiência do usuário (UX).
